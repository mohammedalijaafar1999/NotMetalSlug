# IRON RUCKUS

An original arcade run-and-gun shooter for the browser — procedural pixel art, synthesized
chiptune audio, six missions, vehicles, hostages, bosses and 1–2 player co-op.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm test           # unit + content validation + headless autopilot runs of every mission
npm run build      # dist/ + dist/iron-ruckus.html (single self-contained file)
```

See `docs/DESIGN.md` (game design) and `docs/ARCHITECTURE.md` (engine & content contracts).
